# Oakdb

[![CI](https://github.com/InryeolChoi/Oakdb/actions/workflows/ci.yml/badge.svg)](https://github.com/InryeolChoi/Oakdb/actions/workflows/ci.yml)

A key-value database engine written in Rust, built to learn DBMS internals: storage engine, crash recovery, concurrency and transactions.

Design decisions are recorded in [`docs/adr/`](docs/adr/).

# 첫 2개월의 범위와 영역별 깊이

장기적으로는 relational/document/vector 모델을 지원하는 DB를 목표로 하지만, 첫 2개월은 핵심 저장 엔진의 신뢰성과 동시성 확보에 집중한다. 영역별 깊이는 다음과 같이 차등화한다: 저장 엔진과 장애 복구, 동시성과 트랜잭션은 **핵심**; 쿼리 처리와 서버 엔지니어링은 **최소 기능**(서버는 성능 측정 포함); 분산 시스템은 **추후 확장**으로 미루고 이번 범위에서 제외한다.

## Consequences

- 상위 데이터 모델(relational/document/vector)을 나중에 올릴 수 있도록 엔진의 경계는 확장 가능하게 두되, 2개월 안에는 그 상위 모델을 구현하지 않는다.
- "완료"의 기준은 기능 목록이 아니라 설계 근거(ADR), 장애 테스트, 벤치마크, 동시성 검증 결과가 갖춰졌는지다.
